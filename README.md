# Surreal Park V2

Site institucional do Surreal Park (Camboriú/SC). Astro 7 estático, TypeScript estrito, CSS próprio a partir de `docs/DESIGN-SYSTEM.md`, GSAP e Lenis.

## Rodar

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # gera dist/
npm run check    # typecheck
```

Requer Node 22+. Variáveis em `.env.example`.
